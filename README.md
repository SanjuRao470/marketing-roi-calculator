# Marketing ROI Calculator

Interactive **Marketing ROI / Growth Calculator** for Blue Moon Marketing — built with React, JavaScript, and Tailwind CSS.

## Features

- Three-step input flow: business information, marketing investment & goals, growth assumptions
- Live calculation of leads, customers, revenue gap, marketing investment, ROI (gross-profit based), and ROAS
- Results dashboard with revenue chart, investment breakdown, acquisition funnel, and scenario comparison
- Lead capture form for strategy consultation requests
- Responsive layout for desktop, tablet, and mobile
- Default values and field tooltips per product spec

## Development

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```
